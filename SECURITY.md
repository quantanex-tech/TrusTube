# Reporting access-control problems

Use **Security → Report a vulnerability** on GitHub for sensitive problems,
especially ways to reach unapproved content or bypass parent access. Include the
version and minimal reproduction with synthetic data; exclude PINs, credentials,
family information and signed URLs.

If private reporting is unavailable, open a minimal issue asking for a private
contact route without publishing exploit details or personal data.

Only the latest alpha is actively developed. This remains a supervised-testing
prototype. Full containment, recurring daily allowances and PIN recovery have not
been established. Clearing app data resets local setup.
